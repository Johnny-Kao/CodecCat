# Help and support

CodecCat is an open-source project maintained on a best-effort basis, not a commercial support service.

- **Install/API question:** review the [README](README.md), [PyPI page](https://pypi.org/project/codeccat/) and [public API contract](docs/STABILITY.md). If still blocked, [open an Issue](https://github.com/Johnny-Kao/CodecCat/issues/new/choose) using the question template.
- **Reproducible defect:** use the bug form; include a minimal, non-sensitive test case and environment.
- **Feature or performance request:** read the [roadmap](ROADMAP.md) first and open the relevant template.
- **Security concern:** follow [SECURITY.md](SECURITY.md); avoid public sensitive reports.
- **Third-party rights inquiry:** see [RIGHTS_AND_PROVENANCE.md](RIGHTS_AND_PROVENANCE.md).

Please do not share private user files, passwords, personally identifiable text or proprietary corpora just to reproduce an encoding issue. Replace them with minimized synthetic bytes where possible.

There is no guaranteed response time, support contract or fixed maintenance schedule.
